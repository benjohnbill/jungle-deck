# AGENTS.md — jungle-deck

A Claude Code skill that builds 2-minute Krafton Jungle presentation decks
on top of `frontend-slides`. The design is in `SPEC.md`.

## Agent skills

### Issue tracker

Issues live in GitHub Issues of benjohnbill/jungle-deck, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default labels: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
